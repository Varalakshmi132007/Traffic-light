# Traffic Light Project

## Description

This project is a simple **Traffic Light** created using **HTML** and **CSS**.
It displays three colored lights:

* Red
* Yellow
* Green

The project helps beginners understand:

* HTML structure
* CSS styling
* Flexbox alignment
* Colors and shapes in CSS

---

## Technologies Used

* HTML5
* CSS3

---

## Project Structure

```text
Traffic-Light/
│
├── index.html
└── border.css
```

---

## Features

* Realistic traffic light design
* Circular colored lights
* Flexbox layout
* Beginner-friendly code

---

## How to Run

1. Download or clone the project
2. Open the folder in VS Code
3. Make sure:

   * `index.html`
   * `border.css`
     are in the same folder
4. Open `index.html` using Live Server
